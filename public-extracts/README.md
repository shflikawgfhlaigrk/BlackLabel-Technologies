# Public-extract staging

Nothing in this directory is approved for public release yet.

Each future extract gets its own directory and must include:

- `README.md` with scope and omissions.
- `LICENSE` with an explicitly approved license.
- `SETUP.md` proved on a clean environment.
- Tests and synthetic fixtures.
- `DISCLOSURE-REVIEW.md` with secret, privacy, ownership, dependency, and portability results.

Do not copy a subtree from a production or client repository into this directory. Reconstruct the smallest generic example and prove it independently.
