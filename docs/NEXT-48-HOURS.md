# First 48 hours

Start date: 2026-07-10

## Outcomes

1. Stop public delivery bypasses and false-success purchase flows.
2. Stop development builds from replacing trusted production apps.
3. Establish one release matrix that distinguishes source, build, installed artifact, runtime, commerce, and clean-install truth.
4. Correct public claims that exceed live runtime behavior.
5. Create the private company archive and site specification.

## Work order

### 0–6 hours: containment and record

- Create this private repository and snapshot the GitHub inventory.
- Block direct Sunset package access and make the thanks route require delivery proof.
- Disable or relabel the AS Golf false-success pre-order path until the system uses a real order/payment source.
- Add a production-install guard to development build scripts.

### 6–18 hours: truth and release controls

- Generate `PLATFORM/SHIP-MATRIX.md` from direct evidence.
- Correct Ace public copy so it does not claim an active schedule when its conductor is not dispatching.
- Define a compatible manifest schema and alias plan for every product slug.
- Record unsafe GitHub default branches and unpushed release commits; do not merge them blindly.

### 18–36 hours: portability

- For each app, enumerate bundled versus external runtime dependencies.
- Design first-run setup for every required helper or service.
- Define a clean-user acceptance test with no source checkout, existing LaunchAgent, Homebrew path, or developer secret.
- Separate development app names/paths from production app names/paths.

### 36–48 hours: site and disclosure

- Approve the image-generated site concept.
- Implement a private `noindex` preview from the approved concept.
- Prepare one synthetic public-extract candidate and run the disclosure gate.
- Decide whether the company site uses a new cleared name or stays under Black Label Bots.

## Completion evidence

No item is complete without the applicable test output, deployed response, Git commit, installed-artifact check, or live browser proof. A local source edit by itself is not completion.
