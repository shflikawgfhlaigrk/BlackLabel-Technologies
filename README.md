# Black Label company archive

Private source-of-truth repository for the Black Label software portfolio, client-system archive, public-extract policy, and future company site.

`BlackLabel-Technologies` is a working repository name, not a cleared public brand. As of 2026-07-10, the exact Black Label Technologies name and dot-com are already used by an unrelated technology business. Do not publish or attach a custom domain until the name is cleared or replaced.

## What belongs here

- Evidence-backed portfolio status and release history.
- Architecture and dependency maps.
- Sanitized case-study records.
- Public-extract candidates that pass the disclosure gate.
- The company-site specification and, after visual approval, its source.

## What never belongs here

- Production application source copied from private repositories.
- Client source, customer data, leads, orders, or private business records.
- Secrets, signing identities, provisioning profiles, tokens, credentials, or live database files.
- Local-machine paths or bootstrap patches presented as a distributable setup.
- Claims that have not been verified against the live product or installed artifact.
